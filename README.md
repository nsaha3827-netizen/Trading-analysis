# Trading-analysis
Excel-based Forex &amp; CFD position size calculator supporting XAUUSD, BTCUSD, GBPJPY, EURUSD, and GBPUSD. Built with dynamic pip value logic and risk-based lot sizing. Designed for disciplined trading and Power BI analytics integration.

# Project Overview

This project is a universal Forex & CFD Position Size Calculator built in Microsoft Excel.

It automatically calculates optimal lot size based on:

Account Balance

Risk Percentage

Entry Price

Stop Loss

Instrument Type

The calculator ensures disciplined risk management and removes emotional position sizing.

# Core formula in  excel
Risk Amount = Account Balance × Risk %
Lot Size = Risk Amount ÷ (Stop Loss Points × Pip Value per Lot)
